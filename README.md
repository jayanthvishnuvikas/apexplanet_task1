## Run locally

## GitHub Pages deployment

1. Create a public GitHub repository, e.g. `apexplanet-task1-portfolio`.
2. Open a terminal in this folder and run:

```bash
git init
git add .
git commit -m "Create personalised portfolio structure"
git branch -M main
git remote add origin https://github.com/jayanthvishnuvikas/apexplanet-task1-portfolio.git
git push -u origin main
```

3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, and Save.
5. Wait for deployment. The public URL will be `https://jayanthvishnuvikas.github.io/apexplanet-task1-portfolio/` if that repository name is available and configured.
